# 随心记事本

外观和操作与 Windows 记事本一致的纯文本编辑器，增加了多标签页、自动保存、存档历史和程序内更新。程序是一个约 160 KB 的 exe，运行在 Windows 自带的 .NET Framework 4.8 上，不需要另装运行库。

## 下载安装

在 [Releases](https://github.com/hit1190100321/SuixinNotepad/releases/latest) 页面下载 `SuixinNotepad-Setup-<版本>.exe` 并运行。支持 Windows 10 和 11。

## 功能

**打开即写。** 启动时恢复上次的所有标签页、光标位置和当前标签页；没有标签页时新建一个空白笔记。U 盘、网络盘上暂时打不开的文件照样保留标签，切到这个标签时提示无法打开，并询问是否关闭它。关闭程序不会询问是否保存，也不会清掉标签页。只有“文件 > 清空标签页”会关闭全部标签页，笔记文件本身仍保留在磁盘上。

**标签页数量。** 可以一直新建标签页，程序最多保留 30 个。超出时自动关闭最久没有查看的标签页（内容先写回文件），状态栏会提示关闭了哪个。写不回文件的标签页不会被自动关闭。

**自动保存。** 停止输入 1.5 秒后，内容写回文件。写回失败时标签变红，每 10 秒重试一次。新建的笔记没有指定位置，会保存到默认文件夹“文档\随心记事本”，先用临时文件名 `无标题-20261017-173651.txt`，标签上显示正文第一行。第一行写完、换到第二行时，文件自动改名为第一行的内容，例如 `会议记录.txt`，之后修改第一行不会再改名。第一行是空行时，以第一个有文字的行为准。文件名中不能用的字符（如 `/`、`:`）换成下划线，超过 50 个字的部分截掉，与已有文件重名时加 `-2`、`-3`。重命名默认文件夹中的笔记后，它仍留在默认文件夹。用“另存为”指定位置后，笔记改存到新位置，默认文件夹中的原文件删除，存档历史一并迁移。空白的新笔记不会生成文件。

**Markdown。** .md 文件按纯文本编辑，标记原样显示，自动保存、存档历史、重命名与 .txt 文件相同。另存为时可以选择 Markdown 类型，已是 .md 的文件默认仍存为 .md；重命名时直接改扩展名也可以。

**手动保存时存档。** 每次按 Ctrl+S，除了写回文件，还在备份位置（`%LOCALAPPDATA%\SuixinNotepad\Backups`）为这个文件存一份副本。存档按文件的完整路径分开存放。内容与上一份存档完全相同时不重复存档。自动清理会删除一年以前的存档，并让每个文件最多保留 50 份，超出时删除最旧的。

**标签页历史。** “文件 > 标签页历史”（Ctrl+Shift+O）按查看时间列出看过的文件，按天分组，最近的在前，已打开的标签页用粗体显示。可以按名称或路径搜索，双击或按回车打开；已关闭的标签页由此找回，默认文件夹中的笔记找回后仍按笔记处理。关闭的空白笔记不记入历史。历史最多保留 500 个文件，可以用“从历史中移除”删掉不需要的记录。

**存档历史。** “文件 > 存档历史”（Ctrl+Shift+H）按时间列出当前文件的所有存档，右侧预览内容。恢复某个版本前，程序先对当前内容做一次手动保存（也就产生一份存档），再整体替换为所选版本；替换可以用 Ctrl+Z 撤消（只读文件的恢复不能撤消）。恢复前的这次保存触发清理时，要恢复的那份存档不会被删除。

**设置。** “文件 > 设置”可修改默认保存位置、开关自动备份和自动清理、查看备份位置、填写更新地址、查看和更改 .txt 文件的默认打开程序。关闭自动备份时，自动清理同时失效。

**默认打开程序。** 安装时勾选“设为 .txt 文件的默认打开程序”，或在设置中点“更改...”，会弹出 Windows 的“选择打开方式”对话框，选中随心记事本并点“始终”后生效。Windows 不允许程序自行修改默认程序，必须由用户在这个对话框中确认；想换回其他程序，也在同一个对话框里选择。

**记事本原有功能。** 新建、打开、另存为、页面设置、打印；撤消/重做（多级）、剪切、复制、粘贴、删除、使用 Bing 搜索、查找、查找上一个/下一个、替换、全部替换、转到行、全选、插入时间/日期；自动换行、字体；缩放（也可按住 Ctrl 滚动鼠标滚轮）、状态栏。状态栏显示行列、字符数、缩放、换行符和编码，点击换行符可以修改。以 `.LOG` 开头的文件每次打开时在末尾追加时间。粘贴时只粘贴纯文本。

**外部修改。** 文件被其他程序修改后，切回本程序时会自动重新载入。每次写回文件前也会检查一次：本程序里没有未写回的修改时直接重新载入，有修改时询问是重新载入还是用当前内容覆盖。

**编码。** 支持 UTF-8（带或不带 BOM）、UTF-16 LE/BE、UTF-32 LE/BE、GB18030、GBK、Big5、Shift-JIS、EUC-JP、EUC-KR，以及西欧、中欧、西里尔文（Windows-1251、KOI8-R）、希腊文、土耳其文、希伯来文、阿拉伯文、波罗的海文、越南文、泰文的 Windows 代码页。打开时自动识别：先看 BOM，再看是否为 UTF-8，最后在 GB18030、Big5、Shift-JIS、EUC-KR、Windows-1252 中挑出解码结果最像正常文字的一种，系统默认编码（简体中文系统为 GB18030）优先。保存时保持原编码和原换行符，没有 BOM 的 UTF-16 文件保存后仍没有 BOM。一个文件中混用了多种换行符时，打开时状态栏会提示，修改后保存时统一为第一处换行的形式。

识别错了时，点状态栏的编码，在“通过编码重新打开”中选择正确的编码；“通过编码保存”则把当前内容改存为另一种编码。选定的编码会记住，下次打开不再自动识别。内容中有目标编码无法表示的字符时，不能选择这种编码保存；自动保存遇到这种情况时改用 UTF-8。

**防止写坏文件。** 含有 NUL 字节且不是 UTF-16 的文件（epub、docx、图片等）按二进制文件处理，拒绝打开；超过 64 MB 的文件也不打开。以下两种文件以只读方式打开，状态栏编码后显示“（只读）”，自动保存和手动保存都不会写回原文件：

- 文件中有无法按当前编码识别的字节。可以换一种编码重新打开，或另存为新文件后继续编辑。
- 文件中有编辑控件无法原样保留的特殊字符（Unicode 行分隔符、段分隔符等）。可以另存为新文件，这些字符会被换掉。

只读的文件恢复存档时，先把磁盘上的原始内容原样存一份档。

同一个文件即使经由不同的路径写法打开（大小写、8.3 短文件名、符号链接、硬链接），也只会出现在一个标签页里。写入时先写临时文件再替换原文件；文件有多个硬链接、所在目录不允许新建文件或文件系统不支持替换时，改为直接覆盖原文件，保持硬链接和符号链接不断开。

**其他。** 只运行一个程序窗口，从资源管理器再打开 txt 或 md 文件时会在已有窗口中新开标签页，即使已有窗口正显示着提示框也一样。标签页可拖动排序，中键关闭，双击空白处新建。Ctrl+Tab、Ctrl+PgUp/PgDn 切换标签页。

| 操作 | 快捷键 |

| 时间/日期 | F5 |

## 数据位置

| 内容 | 位置 |
| --- | --- |
| 程序 | `%LOCALAPPDATA%\Programs\SuixinNotepad` |
| 默认保存位置 | `文档\随心记事本`（可在设置中修改） |
| 设置、会话、标签页历史 | `%LOCALAPPDATA%\SuixinNotepad\settings.json`、`session.json`、`history.json` |
| 存档 | `%LOCALAPPDATA%\SuixinNotepad\Backups\<文件名>_<路径哈希>\` |
| 错误日志 | `%LOCALAPPDATA%\SuixinNotepad\error.log` |

卸载只删除程序本身，笔记、存档和设置都会保留。

## 构建

需要 .NET SDK 8 或更高版本（只用来编译，程序本身运行在 .NET Framework 4.8 上）。

```powershell
.\build.ps1                                  # 运行测试、编译、生成安装包
.\build.ps1 -Proxy http://127.0.0.1:7890     # 首次构建下载 Inno Setup 时走代理
.\build.ps1 -SkipTests
```

首次构建会从 nuget.org 下载 Inno Setup 6.7.1 到 `tools\`，并校验 SHA-256。构建产物：

- `build\app\`：编译好的程序。
- `dist\SuixinNotepad-Setup-<版本>.exe`：安装包。按当前用户安装，不需要管理员权限，安装后本程序出现在 .txt、.md 文件的右键“打开方式”列表和 Windows 的“默认应用”设置中；可选创建桌面快捷方式、设为 .txt 文件的默认打开程序。静默更新不会弹出默认程序对话框。
- `dist\latest.json`：更新清单，内容为版本号、安装包文件名和 SHA-256。

只运行测试：`dotnet test tests\SuixinNotepad.Tests`。

## 发布与更新

默认更新地址是 `https://github.com/hit1190100321/SuixinNotepad/releases/latest/download/`，即 GitHub 上最新发布版本的附件。发布新版本的步骤：

1. 修改 `Directory.Build.props` 里的 `<Version>`。程序版本、安装包版本和更新清单都从这里读取。
2. 运行 `.\build.ps1`。
3. 在 GitHub 上新建发布，标签为 `v<版本>`，把 `dist\` 下的安装包和 `latest.json` 都作为附件上传：`gh release create v<版本> dist\*.exe dist\latest.json`。

也可以自己架设更新位置：把 `dist\` 下的两个文件放到网站目录（如 `https://example.com/suixin/`）或共享文件夹（如 `\\server\share\suixin`），再在程序的“设置 > 更新地址”中填写这个位置。地址也可以直接写到 `latest.json`。网站必须用 https：清单里的 SHA-256 和安装包来自同一个地方，只有来源可信时校验才有意义，所以不接受 http 地址。清单放在文件夹中时，安装包必须和清单在同一个文件夹。更新地址留空则不检查更新。

程序启动时每 24 小时检查一次更新，有新版本时状态栏显示“新版本 x 可用”，点击即可更新；也可以用“帮助 > 检查更新”。更新时程序下载安装包、校验 SHA-256、保存所有内容后退出，安装包静默安装到原位置，完成后自动重新打开程序，标签页照旧。

## 项目结构

```
src/SuixinNotepad/
  Core/        与界面无关的逻辑：文本编解码、存档、设置与会话、查找、更新、单实例
  UI/          主窗口（MainForm.*）、编辑控件、标签栏、各对话框、打印
tests/SuixinNotepad.Tests/   xunit 测试
installer/     Inno Setup 脚本和简体中文语言文件
build.ps1      构建脚本
```
