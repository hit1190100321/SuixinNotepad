本项目为一个随心记事本windows程序，要求发布可进行安装与更新的windows安装包。
本项目的目的是改进windows自带的记事本应用。
本项目期望的使用方式是：
打开该程序后会自动跳出上次的记事本txt或新打开的记事本txt。界面和windows自带记事本界面一样。但是要求有以下新功能：所有没有指定记事本位置的记事本默认自动保存在一个文件夹下，不需要用户手动选择保存位置。只有当用户指定一个位置时，记事本才默认保存为该新位置。
用户每一次手动保存，除在txt存在位置保存外，还会在一个备份位置给出一个该次保存的备份。备份跟随txt名称（也即路径）走，留存条件是“备份历史不超过一年”“该txt名称的备份个数不超过50份”，每次手动保存都会检查备份，删除一年以上的备份，超过备份个数时，删除最老的备份。该功能称之为自动备份和自动清理功能，默认开启。用户可以选择关闭自动清理功能，关闭自动备份功能时，视同一起关闭自动清理功能。
用户只有点击清空标签页，才会清空所有的标签页。否则用户每次关掉记事本，都不会清掉标签页，下次打开时，还是之前的标签页。关掉记事本也不会弹框让用户保存或者选择保存位置，因为要么已经由用户指定了位置，要么就是默认位置。
用户可以很方便的查看该txt的存档历史并随时复原到一个备份中，每次执行恢复备份操作，会对恢复备份前的内容执行一次手动保存。
同时该记事本也支持windows原生笔记本的其他功能
该记事本要求轻量化，对电脑负担小。
无命名的txt在第一次从第一行换到第二行时自动命名。可以一直新建标签页，最多保留最近的30个标签页。支持按照查看时间轴查看标签页历史，以便寻找历史txt。
